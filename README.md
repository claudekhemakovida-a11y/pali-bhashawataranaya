# පාලි භාෂාවතරණය – පළමුවැනි පොත

අග්ගමහා පණ්ඩිත පොල්වත්තේ බුද්ධදත්ත ස්වාමින් වහන්සේ විසින් රචිත පාලි අධ්‍යයන ග්‍රන්ථ මාලාවේ පළමුවැනි පොත ඇසුරෙන් සැකසූ ඉගෙනුම් ඇප් එක.

- පාඩම් – පරිච්ඡේද 19
- අභ්‍යාස – වාක්‍ය 1,148 (පද අනුව විකල්ප සහිතව)
- ප්‍රශ්නාවලිය – බහුවරණ ප්‍රශ්න 5,700
- තේමා – ලා රන්, අළු, අඳුරු
